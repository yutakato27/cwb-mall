# cwb-mall
Curitiba Malls is a web project created to centralize information about shopping malls in Curitiba (CWB) in one place.

The website allows users to explore malls around the city and find information about their stores, restaurants, events, entertainment options, services, and other attractions.

The main goal is to make it easier to discover what each mall has to offer and what is currently happening around Curitiba.

## About the Project

Curitiba has several shopping malls, each with different stores, restaurants, events, cinemas, services, and experiences.

Instead of searching through different websites and social media pages, **Curitiba Malls** brings this information together in a single platform.

Users will be able to:

- Explore shopping malls in Curitiba
- View information about each mall
- Discover stores and restaurants
- Check current and upcoming events
- Find entertainment and leisure options
- Explore services available at each location
- View opening hours and other useful information
- Discover new places and activities around the city

## Main Features

### Malls

Browse the shopping malls available in Curitiba and access a dedicated page for each location.

Each mall may include information such as:

- Name
- Address
- Opening hours
- Description
- Photos
- Contact information
- Available services

###  Stores

Explore the stores available in each mall.

Stores can be organized by categories such as:

- Fashion
- Beauty
- Technology
- Home
- Sports
- Accessories
- Services

### Food & Restaurants

Discover restaurants, cafés, fast-food options and other places to eat inside each mall.

###  Events

Check events happening at Curitiba's malls, including:

- Seasonal events
- Exhibitions
- Children's activities
- Workshops
- Shows and performances
- Promotional events
- Special mall attractions

### Entertainment

Find entertainment options such as cinemas, arcades, playgrounds and other leisure activities.

## Technologies

This project is developed using:

- HTML5
- CSS3

The website focuses on reusable components and a consistent visual identity across all pages.

## Objective

The objective of Curitiba Malls is to create a simple and organized platform where people can discover **where to shop, eat and have fun in Curitiba's malls**, as well as stay informed about events and activities happening around the city.
